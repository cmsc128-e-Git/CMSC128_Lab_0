# Dev Instructions
- Requires Node.js 22.13 or newer (check with `node -v`)
- Open terminal in vscode
```
    cd masstrack
    npm install
```
- Then you can begin developing!
### To run the app type in the terminal
```
    npx expo start
```

### To access the app's look
